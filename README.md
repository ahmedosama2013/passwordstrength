# 🔐 Password Strength Analyzer

A sleek website where you enter your password and instantly see how strong it is.

## ✨ Features

* **🛡️ Real-Time Security Audit:** Evaluates criteria such as minimum length, uppercase/lowercase letters, numbers, and special symbols dynamically.
* **📊 Interactive Visual Meter:** Smooth animated strength bar with qualitative score labels ranging from **Weak** ⚠️ to **Excellent** 🏆.
* **👁️ Show/Hide Toggle:** Easily toggle password visibility for a better user experience.
